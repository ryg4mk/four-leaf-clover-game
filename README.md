# 四つ葉のクローバーを探すゲーム

大量のクローバーの中から、四つ葉のクローバーを1つだけ探すスマートフォン向けタイムアタックゲームです。

## 現在の仕様

- ユーザー提供のクローバー画像をゲーム素材として使用
- 1枚目・2枚目を四つ葉候補として使用
- 3枚目を三つ葉として使用
- 四つ葉は毎回1枚だけ出現
- 四つ葉画像は2種類からランダムで選択
- 四つ葉の位置も毎回ランダム
- 四つ葉の周囲に最低限の空間を確保し、三つ葉に埋もれないよう調整
- 描画順でも四つ葉を必ず最後に描き、常に最前面に表示
- 誤タップを含む総タップ回数を裏でカウント
- クリア画面にタイム・タップ回数・BESTを表示
- BEST TIMEはlocalStorageに保存
- GitHub Pages対応

## 素材

GitHub Pagesで扱いやすいよう、提供画像をWebPへ縮小圧縮したうえでBase64テキストとして同梱しています。

- assets/fourleaf_a.b64
- assets/fourleaf_b.b64
- assets/threeleaf.b64

ゲーム起動時にこれらを読み込み、画像として復元して使用します。
