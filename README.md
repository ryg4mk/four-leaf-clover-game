# 四つ葉のクローバーを探すゲーム

大量の実写風クローバーの中から、四つ葉のクローバーを1つだけ探すスマートフォン向けタイムアタックゲームです。

## 特徴

- 四つ葉のクローバーは毎回ランダム位置
- 四つ葉は1つだけ
- 大量の三つ葉に紛れる難易度MAX寄りの構成
- Canvasだけで実写風の葉・葉脈・茎・草・光・陰影を描画
- 誤タップを含めた総タップ回数を裏でカウント
- クリア画面にタイム・タップ回数・BESTを表示
- BEST TIMEはlocalStorageに保存
- スマートフォン縦画面対応
- 外部素材・外部ライブラリなし
- GitHub Pagesでそのまま公開可能

## 公開方法

1. ZIPを展開します。
2. `index.html`、`style.css`、`game.js`、`README.md` をGitHubリポジトリのルートへアップロードします。
3. GitHubの `Settings → Pages` を開きます。
4. `Deploy from a branch` → `main` → `/(root)` を選択します。
5. 数分後にGitHub PagesのURLから遊べます。

## ゲーム仕様

タイトル：四つ葉のクローバーを探すゲーム

四つ葉を見つけた瞬間にタイマー停止。
四つ葉以外をタップしてもゲームオーバーにはなりませんが、そのタップも総タップ回数に含まれます。
